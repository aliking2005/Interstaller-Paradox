# 🎮 Interstellar Paradox

Interstellar Paradox est un jeu d'exploration spatial en 3D. Le joueur incarne un explorateur chargé de trouver une planète habitable alors que la Terre est menacée.

---

## Fonctionnalités principales

- Exploration des planètes
- Missions Dangereux avec un objet unique est e trouvr un planète habitable
